# Сайн Моторс Эрдэнэт салбарын нээлт

Тусдаа төсөл. `sainmotors.mn` хавтсыг өөрчлөөгүй.

## Нээх

Node.js 24+ хэрэгтэй. Нэмэлт package суулгахгүй.

```powershell
npm.cmd start
```

Хаяг: **http://localhost:3210**

Өдрийн сонголт: **11.28 (Бямба) тест драйв өдөрлөг** → 10:00, 12:00, 14:00, 16:00, 18:00; **11.29 (Ням) нээлт** → 17:00. Гар утасны улаан товч доод ирмэгээс 20px зайтай харагдана. Форм руу очиход хөвөгч товч нуугдаж, формын доторх улаан товчоор илгээнэ. Checkbox байхгүй; холбогдох зөвшөөрлийн тайлбар товчны доор бий.

Эхний **250 бодит бүртгэлд** үлдсэн нөөцөөс бэлэг санамсаргүй онооно. Нийт нөөцөд **50 шүхэр, 25 USB багц, 20 хуванцар дугаар бичигч, 155 дугаар бичигч** багтана. Бэлэг оноогдсон зочин бүртгүүлсний дараа **азын хүрд** эргүүлж бэлгээ мэднэ. Нэг утасны дугаарт нэг бэлэг онооно. Ижил хүсэлтийг давтан илгээхэд эсвэл хуудсаа шинэчлэхэд тухайн бэлгийг харуулна. **251 дэх бүртгэлээс** эхлэн бүртгэл хадгалагдаж, **«Бэлгийн нөөц дууссан»** гэж харуулна.

Apps Script нь Google Sheet дээрх үлдэгдлийг тоолж, бэлгийг нэг түгжээний дотор сонгон хадгална. Өмнөх хоёр туршилтын бүртгэлийг (`9c4a6cb0-16ae-4c30-b539-f7f92a3443c5`, `fbdea9e6-01c6-4a01-9f4f-544de11b2bc3`) үлдэгдэл тооцохдоо алгасна. Бодит бүртгэлийн хуучин «Гарын бэлэг» нэрийг дараагийн хүсэлтээр «Дугаар бичигч» болгон шинэчилж, 155 ширхгийн нэгээр тооцно.

Локал серверийг Google Sheet-тэй холбосон үед Sheet түр тасарвал бүртгэлийг SQLite-д хадгалж, баталгаажих хүртэл хүрдийг нууж хүлээнэ. Ингэснээр түр сонгосон бэлэг дараа нь өөр бэлэг болж солигдохгүй.

Байршил: Sain Motors Эрдэнэт, Alpha Arena Sportainment Center (нээлтийн постероос). Утас 8808-8505. Нээлтийн хөтөлбөрт урлагийн номер, QR уншуулж бүртгүүлсэн эхний 250 хүний бэлгийн мэдээлэл орсон.

## Google Sheet холбох — нэг удаа

Хүлээн авах файл: [ErdenetTestDrive](https://docs.google.com/spreadsheets/d/1argV8PktHaKNvW5_iK0UICcwOkHGDJtEq__PwSOGs2k/edit), `Sheet1`.

Бүртгэл бүр 12 баганатай: хуучин 11 багана + **Бэлэг** (хүрдний бэлгийн нэр). Sheet1 одоо 11 гарчигтай байвал скрипт анхны бүртгэлээр L1-д `Бэлэг` гарчгийг өөрөө нэмнэ. Эвентийн дугаар: `erdenet-opening-2026-11`.

**Аль хэдийн deploy хийсэн бол:** `private/Code.gs`-ийн шинэ кодыг Apps Script-ийн `Code.gs`-д бүхэлд нь солиод хадгална → **Deploy → Manage deployments → ✏ Edit → Version: New version → Deploy**. `/exec` хаяг хэвээр үлдэнэ. Шинэ deployment үүсгэсэн бол доорх 3-р алхмаар хаягаа дахин холбоно.

**250 бэлгийн нөөцийг нийтлэхийн тулд** `npm.cmd run setup` ажиллуулж, одоо ашиглаж буй нууц түлхүүртэй `private/Code.gs` файлыг бэлтгэнэ. Apps Script-ийн шинэ хувилбарыг Netlify сайт шинэчлэгдэхээс өмнө deploy хийнэ.

1. Sheet-ээ нээгээд **Extensions → Apps Script** рүү орно. Энэ төслийн `private/Code.gs` файлын бэлэн кодыг хуулж, Apps Script-ийн `Code.gs` дотор хадгална. Энэ файл нууц холболтын түлхүүр агуулдаг тул нийтэд илгээхгүй.
2. **Deploy → New deployment → Web app**. **Execute as: Me**, **Who has access: Anyone** гэж сонгоод Google-ийн зөвшөөрлийг өөрөө өгнө. Web app нь зөв нууц түлхүүртэй хүсэлтийг л авна; бүртгэлийн жагсаалт уншуулах API байхгүй.
3. Гарсан `/exec` хаягийг холбоно:

```powershell
npm.cmd run connect -- https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec
```

Ажиллаж байгаа сервер 30 секундын дотор тохиргоог уншина. Хүлээгдэж байсан бүртгэлийг автоматаар нөхөж илгээнэ. Шинээр deploy хийсний дараа заавал бодит туршилтын бүртгэл Sheet-д орсныг шалгана.

Apps Script-ийг өөрчлөх бол шинэ deployment/version гаргана. Sheet1-ийн баганын нэр, дарааллыг солихгүй; скрипт тохирохгүй хүснэгтэд бичихээс татгалзана.

## Хадгалалт

Бүртгэлийг эхлээд `data/leads.sqlite` дотор хадгална. Google түр ажиллахгүй бол `pending` хэвээр хадгалж, 30 секунд тутам дараагийн оролдлогыг шалгана. Давтан алдаа гарвал оролдлогын зай 5 минут хүртэл өснө. Хүлээгдсэн бүртгэлийг автоматаар устгахгүй.

Ижил утасны дугаараар аль ч өдөр дахин бүртгүүлэхэд **Энэ дугаар бүртгэгдсэн байна.** гэж харуулна. Ижил хүсэлтийн ID-тай техникийн дахин оролдлого өмнөх бүртгэлээ буцаана. Sheet-д бичсэн баталгааг авсны дараа л веб дээр **Та бүртгэгдлээ** гэж гарна. URL хараахан холбоогүй үед хүсэлтийг дотоод санд `pending` төлөвтэй авна; энэ нь Google-д орсон гэсэн үг биш.

`.env`, `private/`, `data/` нь нийтэд харагдах веб файлуудад багтахгүй. Хувийн мэдээллийг консольд бичихгүй. Хэрэглэгчийн утас, нэрийг хөтөчид зөвхөн илгээж дуусаагүй зөвшөөрсөн хүсэлтийг дахин илгээхэд түр хадгална; сервер хүлээж авмагц арилгана.

## Netlify дээр нийтлэх

`netlify.toml` бэлэн: вэб `public/`, бүртгэлийн функц `netlify/functions/leads.mjs` (`POST /api/leads`).

- Netlify-д байнгын диск байхгүй тул функц бүртгэлийг **шууд Google Sheet рүү** бичнэ. Хэн ямар бэлэг авсныг Sheet хадгална: нэг утасны дугаар бүх эвентэд нэг бэлэгтэй (Apps Script утсаар өмнөх мөрийг хайж бэлгийг нь давтан өгнө).
- Google түр ажиллахгүй бол функц 503 буцаана; зочны хөтөч хүсэлтийг хадгалж, дахин илгээнэ (ижил хүсэлтийн ID тул давхар мөр үүсэхгүй).
- Netlify → Site configuration → Environment variables: `GOOGLE_SHEETS_WEBHOOK_URL`, `LEAD_WEBHOOK_SECRET` (`.env`-тэй ижил утга).
- Apps Script дээр **хамгийн сүүлийн** `private/Code.gs` deploy хийгдсэн байх ёстой (бэлгийг хариунд буцаадаг хувилбар); эс тэгвэл функц бүртгэлийг 503-аар татгалзана.
- GitHub-ийн `main` салбар руу push хийх бүрт Netlify автоматаар дахин нийтэлнэ.

## Нийтэд ажиллуулах (Node сервер)

Энэ нь **локал ажиллаж байгаа хувилбар**. Компьютер унтарвал эндэх сервер ажиллахгүй. Нийтэд ашиглахад Node 24+ сервер, **байнгын диск**, HTTPS, тогтмол нөөцлөлт хэрэгтэй. `public/` хавтсыг дангаар нь Netlify/static hosting руу хуулахад бүртгэлийн API ажиллахгүй.

Серверийн `PUBLIC_ORIGIN`-д бодит HTTPS домэйныг, `HOST=0.0.0.0`, `DATA_DIR`-д байнгын дискний замыг тохируулна. Google холболтын URL, ижил `LEAD_WEBHOOK_SECRET`-ийг серверийн нууц тохиргоонд өгнө. SQLite файлыг устгах, дискийг алдах эрсдэлийг программ дангаар хамгаалахгүй; production-д нөөцлөлт зайлшгүй.
