# Сайн Моторс · Эрдэнэт Test Drive

Тусдаа төсөл. `sainmotors.mn` хавтсыг өөрчлөөгүй.

## Нээх

Node.js 24+ хэрэгтэй. Нэмэлт package суулгахгүй.

```powershell
npm.cmd start
```

Хаяг: **http://localhost:3210**

Өдрийн сонголт: 11.21 → 17:00; 11.22 → 10:00, 12:00, 14:00, 16:00, 18:00. Гар утасны улаан товч доод ирмэгээс 20px зайтай харагдана. Форм руу очиход хөвөгч товч нуугдаж, формын доторх улаан товчоор илгээнэ. Checkbox байхгүй; холбогдох зөвшөөрлийн тайлбар товчны доор бий.

Байршлыг сүүлд өгсөн постерын **Alpha Arena Sportainment Center** мэдээллээр шинэчилсэн. Огнооны зөрүүг баталгаажуулах шаардлагатай: постерт 11.20, 11:00–20:00; хэрэглэгчийн бүртгэлийн зааварт 11.21–22 гэж өгсөн. Одоогоор тусгайлан заасан 21–22-ны сонголтуудтай локал хяналтын хувилбар хэвээр.

## Google Sheet холбох — нэг удаа

Хүлээн авах файл: [ErdenetTestDrive](https://docs.google.com/spreadsheets/d/1argV8PktHaKNvW5_iK0UICcwOkHGDJtEq__PwSOGs2k/edit), `Sheet1`.

1. Sheet-ээ нээгээд **Extensions → Apps Script** рүү орно. Энэ төслийн `private/Code.gs` файлын бэлэн кодыг хуулж, Apps Script-ийн `Code.gs` дотор хадгална. Энэ файл нууц холболтын түлхүүр агуулдаг тул нийтэд илгээхгүй.
2. **Deploy → New deployment → Web app**. **Execute as: Me**, **Who has access: Anyone** гэж сонгоод Google-ийн зөвшөөрлийг өөрөө өгнө. Web app нь зөв нууц түлхүүртэй хүсэлтийг л авна; бүртгэлийн жагсаалт уншуулах API байхгүй.
3. Гарсан `/exec` хаягийг холбоно:

```powershell
npm.cmd run connect -- https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec
```

Ажиллаж байгаа сервер 30 секундын дотор тохиргоог уншина. Хүлээгдэж байсан бүртгэлийг автоматаар нөхөж илгээнэ. Шинээр deploy хийсний дараа заавал бодит туршилтын бүртгэл Sheet-д орсныг шалгана.

Apps Script-ийг өөрчлөх бол шинэ deployment/version гаргана. Sheet1-ийн баганын нэр, дарааллыг солихгүй; скрипт тохирохгүй хүснэгтэд бичихээс татгалзана.

## Хадгалалт

Бүртгэлийг эхлээд `data/leads.sqlite` дотор хадгална. Google түр ажиллахгүй бол `pending` хэвээр хадгалж, 30 секунд тутам дараагийн оролдлогыг шалгана. Давтан алдаа гарвал оролдлогын зай 5 минут хүртэл өснө. Хүлээгдсэн бүртгэлийг автоматаар устгахгүй.

Ижил event/өдөр/цаг/утас эсвэл ижил хүсэлтийн ID нь давхар мөр үүсгэхгүй. Sheet-д бичсэн баталгааг авсны дараа л веб дээр **Та бүртгэгдлээ** гэж гарна. URL хараахан холбоогүй үед хүсэлтийг дотоод санд `pending` төлөвтэй авна; энэ нь Google-д орсон гэсэн үг биш.

`.env`, `private/`, `data/` нь нийтэд харагдах веб файлуудад багтахгүй. Хувийн мэдээллийг консольд бичихгүй. Хэрэглэгчийн утас, нэрийг хөтөчид зөвхөн илгээж дуусаагүй зөвшөөрсөн хүсэлтийг дахин илгээхэд түр хадгална; сервер хүлээж авмагц арилгана.

## Нийтэд ажиллуулах

Энэ нь **локал ажиллаж байгаа хувилбар**. Компьютер унтарвал эндэх сервер ажиллахгүй. Нийтэд ашиглахад Node 24+ сервер, **байнгын диск**, HTTPS, тогтмол нөөцлөлт хэрэгтэй. `public/` хавтсыг дангаар нь Netlify/static hosting руу хуулахад бүртгэлийн API ажиллахгүй.

Серверийн `PUBLIC_ORIGIN`-д бодит HTTPS домэйныг, `HOST=0.0.0.0`, `DATA_DIR`-д байнгын дискний замыг тохируулна. Google холболтын URL, ижил `LEAD_WEBHOOK_SECRET`-ийг серверийн нууц тохиргоонд өгнө. SQLite файлыг устгах, дискийг алдах эрсдэлийг программ дангаар хамгаалахгүй; production-д нөөцлөлт зайлшгүй.
